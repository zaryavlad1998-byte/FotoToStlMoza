# Практическая работа № 1 — Создание HTML-страницы в соответствии с макетом

Верстка карточки товара «Кирпич огнеупорный ШБ-5» интернет-магазина ТК «Гермес»
по макету Figma (Germes Copy).

## Структура проекта

- `index.html` — страница карточки товара (семантическая разметка);
- `css/style.css` — все стили и медиа-запросы;
- `images/` — графика, нарезанная из макета;
- `favicon.svg` — тематическая фавиконка (домик в фирменном цвете).

## Адаптивность

Страница адаптирована под пять диапазонов экранов, заданных в работе:

| Диапазон | Особенности раскладки |
|---|---|
| 320px–425px | мобильная шапка (логотип, телефон, бургер), краткие характеристики, 3 компактные карточки, мобильный подвал |
| 426px–767px | та же мобильная раскладка с увеличенными отступами |
| 768px–1023px | фиолетовая панель меню, товар в одну колонку, 3 карточки, точки слайдера |
| 1024px–1440px | полная десктопная раскладка: 2 колонки товара, 5 карточек, баннер и хлебные крошки |
| 1441px–1920px | расширенный контейнер и увеличенные интервалы между логотипами партнеров |

## Проверки

- Валидность HTML и CSS подтверждена локальным запуском Nu Html Checker
  (`vnu.jar --also-check-css`) — ошибок нет.
- Кроссбраузерность: используются только широко поддерживаемые свойства
  (flexbox, grid, медиа-запросы), вендорные хаки не требуются.
