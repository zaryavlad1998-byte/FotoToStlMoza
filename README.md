# 🧱 Mosabrik STL Generator

Веб-приложение для преобразования изображений в 3D-мозаики в стиле конструктора Mosabrik с экспортом в STL для 3D-печати.

## ✨ Возможности

- 📸 Drag-and-drop загрузка изображений
- 🎨 Настраиваемая палитра до 4 цветов (HEX/RAL)
- 📏 Размер мозаики от 8×8 до 128×128 пикселей
- 🎚️ Расширенные настройки:
  - Переменная высота блоков (на основе яркости)
  - Настройка высоты блоков (1-10 мм)
  - Толщина основы (0.5-5 мм)
  - Зазор между блоками (0-1 мм)
- 🔮 3D preview с интерактивным вращением
- 💾 Экспорт в STL формат

## 🎯 Как использовать

1. Загрузи изображение (drag-and-drop или клик)
2. Выбери размер мозаики (например, 48×48)
3. Настрой палитру (добавь до 4 цветов)
4. *Опционально*: включи Advanced mode для тонкой настройки
5. Нажми "Сгенерировать 3D Preview"
6. Покрути 3D-модель мышкой
7. Скачай STL файл для печати
